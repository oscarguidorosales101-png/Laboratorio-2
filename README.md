# GourmetReserve

Sistema de gestión de reservas de restaurante diseñado para facilitar la administración de mesas, clientes, horarios y reservas mediante una interfaz clara y un asistente inteligente.

## Características principales

- Gestión y consulta de reservas.
- Administración de mesas y capacidades.
- Registro y gestión de clientes.
- Configuración de horarios de atención.
- Consulta de métricas del restaurante.
- Asistente inteligente para solicitudes de reserva en lenguaje natural.
- Validación de disponibilidad y prevención de conflictos entre reservas.

## Componentes de la Arquitectura

- **Interfaz de usuario:** permite consultar y administrar las reservas del restaurante.
- **Gestión de reservas:** valida solicitudes y aplica las reglas del negocio.
- **Persistencia de datos:** conserva la información necesaria para la operación del sistema.
- **Asistente inteligente:** ayuda a interpretar solicitudes y consultar opciones disponibles.
